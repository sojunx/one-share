# User Stories - oneShare

## Core stories
- As a user, I want to create group and invites my friends, so that we can track shared expenses together.
- As a group member, I want to add an expense (who paid and how to split), so that everyone's share is recorded & updated fairly.
- As a group member, I want to track current balance (who owes whom), so that I know how much I need to pay or receive.
- As a group member, I want to record a payment, so that the balances are updated after settle a debt.
- As a group member, I want to list all expenses, so that I can track the history.
